# Как с этим работать

Миша, это папка финансового бота. Всё о проекте лежит здесь: исследования, утверждённый план, правила для агентов, план разработки и потом код.

1. Открой новую сессию Claude Code именно в папке `finance-bot` (не на рабочем столе) и напиши задачу. Только так включаются агенты команды, скиллы проверки кода, плагины и защита от опасных git-команд. Агент сам прочитает `AGENTS.md`, `CONTEXT.md` и `HANDOFF.md` и поймёт, где остановились.
2. Если работаешь с другой LLM, дай ей прочитать эти три файла, затем файлы нужного этапа.

## Что где

- `HANDOFF.md` - что сделано, где остановились, что ждёт твоего решения.
- `shared/decisions.md` - все твои решения с цитатами и датами.
- `stages/01_research/` - оба исследования: рынок и стек.
- `stages/02_spec/` - утверждённый план (страница v2) и спецификация для агентов.
- `stages/03_plan/` - дорожная карта (по-русски) и пошаговый план фазы 1 для агентов.
- `stages/04_build/` - правила разработки; код появится в `app/`.
- `stages/05_qa/` - проверки и чек-лист твоей приёмки.
- `stages/06_release/` - выпуск на сервер, только с твоего апрува.
- `_config/` - постоянные правила: работа с тобой, код, Telegram, сервер, команда.

Каждый этап начинается с `CONTEXT.md`: что читать, что делать, где остановиться на твою проверку.

## Тестовый бот (нужен к приёмке 6.11, сборке не мешает)

1. В Telegram открой @BotFather, отправь `/newbot`. Имя любое, например `Finance Dev`. Адрес должен кончаться на `bot`, например `misha_finance_dev_bot`. BotFather пришлёт токен.
2. Напиши @userinfobot, он ответит твоим числом `Id`.
3. Запусти в терминале команду ниже. Она спросит токен (при вводе его не видно) и твой id и сохранит их в `app/.env`. Ни мне, ни агентам токен не показывай.

```bash
cd ~/Desktop/finance-bot/app && printf "Токен бота: " && read -rs t && echo && printf "Твой Telegram id: " && read -r i && printf "BOT_TOKEN=%s\nOWNER_ID=%s\n" "$t" "$i" > .env && chmod 600 .env && echo "Сохранено в app/.env"
```
