## Notes for the research notes
- vitest: `@cloudflare/vitest-pool-workers` is deprecated on npm. Use `@cloudflare/vitest-plugin`.
- Drizzle: the docs install `@rc`, but stable 0.45.4 also exposes `drizzle-orm/d1`. Confirm with a test install before relying on stable.
- Static assets: "free and unlimited" has a caveat for `run_worker_first` patterns.
- Deno Deploy Classic: the 20 July 2026 shutdown has already happened. Any Option 5 plan must use the new Deno Deploy.
- grammY Node.js guide: its compatibility date (2024-04-05) comes from a create-cloudflare log. Do not copy it as a current setting.
- Hetzner: hosting_alternatives.md lists lower third-party prices (EUR 3.99, 4.49, 5.49). None is on an official page checked; treat them as unverified.

## Reliability rating
1. Tally: 37 rows, 34 confirmed (some with caveats), 1 wrong, 2 unverifiable. Limits and prices are high reliability: official pages dated 2026 or npm registry values read on 31 Oct 2026.
2. Telegram Serverless: exact for what the page says (snapshot and live page agree). Nothing beyond the page is verified.
3. Weak spots: Cloudflare cron minimum interval (not stated), drizzle-kit on stable (not checked), Hetzner availability (undated page). All WebFetch quotes need a re-check before reuse.
